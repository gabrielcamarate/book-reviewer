# Icons

Os 15 ícones que as telas usam, copiados sem alteração da biblioteca Lucide, versão 0.577.0 (a mesma do `lucide-react` do projeto). São de traço 2, sem preenchimento, em `currentColor`: assumem a cor do texto ao redor.

No código, use os componentes de `lucide-react`. Estes arquivos servem de consulta e para lugares onde a biblioteca não chega.

- `book-open.svg` — a marca no cabeçalho (28px, em `primary`) e a aba "Livro".
- `list.svg` — a aba "Meus livros".
- `sliders-horizontal.svg` — a aba "Opções".
- `plus.svg` — "Novo livro" e "Adicionar termo".
- `chevron-left.svg` — link de voltar e "Trecho anterior".
- `chevron-right.svg` — "Próximo trecho".
- `chevron-down.svg` — abrir as correções de um parágrafo no celular.
- `chevron-up.svg` — fechar as correções de um parágrafo no celular.
- `pause.svg` — "Pausar".
- `download.svg` — os dois botões de baixar o livro.
- `upload.svg` — "Escolher arquivo Word".
- `file-text.svg` — o arquivo escolhido.
- `check.svg` — etapa concluída e "Seu livro está pronto".
- `circle-alert.svg` — cartão de atenção e erro ao abrir. Dentro do círculo de status de 56px, use só o ponto de exclamação.
- `loader-circle.svg` — carregando.

Tamanhos: 20px dentro de botões e links, 22px na barra inferior, 28px na marca.
